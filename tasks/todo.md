## 边界

- 不重新设计 B 型布局，不新增登录、数据库、后台、收藏、统计、评论、自动抓取。
- 不增加资源，不按 0～1 / 1～2 / 2～3 岁细分，不使用“小芽”或“儿童游戏”作为主品牌。
- 不伪造游戏截图、声音状态、免费状态或家庭偏好。
- V2 原型保留为回滚参考，不覆盖。

## 验收停止条件

- Node 校验与测试全部通过；README 同步检查通过。
- 桌面与手机无横向溢出；Lucas 首位且按钮为“查看商店”；源码条目显示“查看项目”。
- 线上 URL 可访问且内容与仓库一致；若外网阻断，区分本站部署失败与第三方目标不可达。
